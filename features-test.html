🎮 How to Use:

Remember Feature:

1. Navigate to any word
2. Click "To remember" button
3. Button turns green and shows "✓ Remembered"
4. Click "Remember" tab to review saved words
5. Click button again to remove from remember list

Search Feature:

1. Type word in search box
2. Press Enter or click 🔍 Search
3. Click on any result to navigate to that word
4. App automatically switches to correct level

Keyboard Shortcuts:

• Arrow keys: Navigate cards
• Space/Enter: Flip card
• P: Play pronunciation
• Enter in search: Perform search

💾 Data Storage:

• Remember list: Stored in localStorage
• Current position: Saved per level
• Search database: Cached in memory
• All data persists between sessions
